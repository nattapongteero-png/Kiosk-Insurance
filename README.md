# Kiosk Insurance — Smart Hospital Kiosk

ต้นแบบหน้าจอตู้ลงทะเบียนอัตโนมัติ (32 นิ้ว แนวตั้ง 1080×1920) พร้อม flow ขอความยินยอมและตรวจสอบประกันสุขภาพ

**ดูต้นแบบ:** https://nattapongteero-png.github.io/Kiosk-Insurance/

## โครงสร้าง
- `preview/` — ต้นแบบ HTML ที่กดใช้งานได้จริง
  - `welcome_v2.html` — หน้าแรกของตู้ (เสียบบัตร / กรอก HN / สแกนหน้า) + modal ความยินยอม
  - `insurance.html` — เลือกแบบประกัน → ส่งข้อมูล (modal) → สรุปผล (ส่งสำเร็จ / ส่งนาน)
- `android/` — โค้ด Kotlin / Jetpack Compose (ยังเป็นเวอร์ชันก่อนปรับตาม Figma)

## หมายเหตุ
- ข้อมูลผู้ป่วยและแบบประกันทั้งหมดเป็นข้อมูลสมมติ
- โลโก้บริษัทประกันนำมาจาก Wikimedia Commons เพื่อใช้ในต้นแบบเท่านั้น
